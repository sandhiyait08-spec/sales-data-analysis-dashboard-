# 📊 Sales Data Analysis Dashboard

📖 Description

The **Sales Data Analysis Dashboard** is an interactive business intelligence project developed to analyze sales performance, monitor key business metrics, and support data-driven decision-making. The dashboard provides a clear visualization of sales trends, revenue, profit, customer behavior, and regional performance through dynamic charts and reports.

It enables business users to identify high-performing products, profitable regions, and sales patterns, helping organizations make informed strategic decisions and improve overall business performance.

---

✨ Features

- Interactive sales dashboard
- Revenue and profit analysis
- Monthly and yearly sales trends
- Region-wise sales performance
- Category and sub-category analysis
- Top-selling products
- Customer segmentation
- KPI cards (Sales, Profit, Orders, Quantity)
- Dynamic filtering using slicers
- Easy-to-understand visual reports
